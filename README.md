# LDPC design

Генерация протографов LDPC-кодов алгоритмом PEG (Progressive Edge Growth)
и расчёт эволюции плотности (Density Evolution, DE) для декодирования методом
распространения доверия (BP) в двоичном канале со стираниями (BEC).

## Быстрый старт

Из корня проекта подключи сабмодули и установи NumPy. Генератор использует
реализацию PEG из сабмодуля `ldpc-for-flash-memory`.

```sh
git submodule update --init --recursive
python -m pip install -r requirements.txt
```

### Построить матрицу протографа

```sh
python ldpc_protograph/ldpc_de_bec/generate_protograph.py
```

Размер и степень столбцов задаются в начале файла
[`generate_protograph.py`](ldpc_protograph/ldpc_de_bec/generate_protograph.py).

| Параметр | Значение | По умолчанию |
| --- | --- | ---: |
| `K` | Число строк (проверочных узлов) | 4 |
| `N` | Число столбцов (переменных узлов) | 8 |
| `L` | Число единиц в каждом столбце, от `1` до `K` | 2 |

С текущими параметрами скрипт создаёт файл
`ldpc_protograph/ldpc_de_bec/data/peg_4x8_l2.txt`. Матрица сохраняется
как текст с пробелами между элементами. Каталог `data/` создаётся автоматически
и исключён из Git.

### Запустить Density Evolution

Запусти Python из корня проекта и загрузи матрицу, созданную на предыдущем шаге.

```python
import numpy as np

from ldpc_protograph.ldpc_de_bec.density_evolution import DensityEvolution

H = np.loadtxt("ldpc_protograph/ldpc_de_bec/data/peg_4x8_l2.txt", ndmin=2)
de = DensityEvolution(epsilon=0.5, protograph=H, iterations=50)
p, q = de.de()

print(p.shape, q.shape)  # (4, 8) (4, 8)
```

## Входные данные и результаты DE

- `protograph` — непустая двумерная матрица `H` со значениями от `0` до `1`
  и хотя бы одним ненулевым элементом. Значения `0` и `1` задают отсутствие
  и наличие ребра. Дробное значение задаёт независимую вероятность наличия
  ребра в релаксированном протографе.
- `epsilon` — вероятность стирания символа в канале, от `0` до `1`.
- `iterations` — неотрицательное целое число итераций BP, по умолчанию `50`.

`de()` возвращает результат последней итерации массивами формы `H`.

| Массив | Значение элемента `[i, j]` |
| --- | --- |
| `p` | Апостериорная вероятность стирания символа `j`, повторённая на всех его рёбрах. |
| `q` | Вероятность стирания в сообщении от проверочного узла `i` к переменному узлу `j`. |

Позиции `H[i, j] = 0` заполнены служебными нулями. Для изолированного символа
вероятность стирания равна `epsilon`. При `iterations=0` массив `p` содержит
`epsilon` на рёбрах, а `q` равно `None`.

Вычисления выполняются в логарифмах. Вызов `de.de(return_logs=True)` возвращает
натуральные логарифмы вероятностей, где нулевой вероятности соответствует `-inf`.
При `return_edge_messages=True` третьим массивом возвращаются итоговые сообщения
от переменных узлов к проверочным.
